Más de 40 skills para editar, recortar, subtitular y crear videos con código. Se instalan con un solo comando y se usan desde una sola puerta: /video-studio elige la herramienta adecuada por ti.

Pega el comando en PowerShell (Windows) o en la Terminal (Mac/Linux). Solo necesitas Git. Después reinicia Claude Code y escribe /video-studio.

Créditos

Video Studio no copia el trabajo de nadie: el instalador descarga cada skill de su repositorio original. Todo el mérito es de sus autores.
